# 紫垣天机 · 紫微斗数排盘

轻量网页端紫微斗数工具：本命盘、飞星四化、真太阳时、农历、运限与格局分析。

## 功能

- **本命盘排盘**（公历 / 农历 + 时辰 + 性别）
- **八字排盘**（四柱、藏干、十神、五行、纳音、空亡、神煞、大运）
- **八字解析**（日主、十神格局、喜用示意、刑冲、神煞、事业六亲、大运阶段）
- **真太阳时**（出生地经度 + 均时差，常用城市快选）
- **经典十二宫盘面**（命宫高亮、身宫/来因宫标记）
- **飞星四化**：生年四化飞入箭头、宫干自化
- **主星 / 辅星 / 杂曜** 显示开关，四化着色
- **大限 / 流年 / 流月 / 流日**
- **盘面皮肤**：三合 · 四化深色 · 精简
- **安星算法**：默认 / 中州（iztro）
- **严格格局** + 格局库文案
- **命例库**：浏览器 localStorage，JSON 导入导出
- **截图保存** PNG

## 启动

```bash
cd web
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

```bash
npm run build   # 产物在 dist/
npm run preview
```
